# Financial-Notification-Bayesian-Network

This program is a Bayesian Network written in Python that is able to classify test financial data. The idea was to train the model to be able to decipher between low, medium, and high priority financial notifcations such as investment updates, statements, bills, and more. It prints a summary of the data and also has a built-in interactive mode so users can feed it their own notificaitons to be classified.
